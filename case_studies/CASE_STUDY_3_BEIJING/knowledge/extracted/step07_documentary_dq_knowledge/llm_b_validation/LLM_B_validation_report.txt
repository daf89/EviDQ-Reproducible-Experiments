### K006
- **ORIGINAL_CLAIM** : REPEATED_IDENTICAL_VALUES -> FLAG (Stuck values PM2.5).
- **SOURCE_FOUND** : YES
- **VERIFIED_DOCUMENT** : Best Practices for Review and Validation of Ambient Air Monitoring Data
- **VERIFIED_SECTION** : 3.2.1 Level 0 / 3.2.2 Level 1 Data Review
- **VERIFIED_PAGE** : 42, 46 (PDF p. 51, 55)
- **MINIMAL_SUPPORTING_PASSAGE** : "Stuck or repeating identical values for more than a few hours/days that can be flagged as suspect and require further investigation" / "8. Look for constantly repeating values... If identified, investigate to determine root cause(s) and document."
- **SOURCE_INTERPRETATION** : Le document signale que des valeurs répétées sont suspectes, mais le seuil ("a few hours/days") est qualitatif et dépend du contexte.
- **CRITERION_EXPRESSION_ASSESSMENT** : OVER_FORMALIZED (La transformation en règle booléenne stricte sans seuil temporel précis est surévaluée).
- **APPLICABILITY_ASSESSMENT** : DIRECT
- **OPERATIONAL_STATUS_ASSESSMENT** : DIAGNOSTIC_ONLY (Nécessite un jugement expert pour définir la durée anormale).
- **ACTION_ASSESSMENT** : FLAG (Correct, suivi de REVIEW).
- **MISSING_INFORMATION** : Seuil temporel précis (nombre d'heures/jours) adapté au site.
- **FINAL_STATUS** : VALIDATED_WITH_RESTRICTION
- **CORRECTION_REQUIRED** : Changer `operational_status` en `DIAGNOSTIC_ONLY`. Préciser que le flagging nécessite une évaluation qualitative de la durée.
